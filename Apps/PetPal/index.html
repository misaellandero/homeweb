Technical Build

A private Apple-platform care system for pet records.

SwiftUI + SwiftData

Models pets, medical events, reminders, attachments, daily logs, and walk sessions with native Apple data tools.

CloudKit + App Groups

Uses private iCloud sync and shared app group storage for companion experiences.

WidgetKit + ActivityKit

Powers glanceable pet updates, reminders, and live walk tracking experiences.

Foundation Models + Vision

Supports assistant-style workflows, food checks, vaccine analysis, and image classification on capable devices.

MapKit + CoreLocation

Tracks walks, routes, and location-aware care history when the user enables it.

Documents + PDF Export

Handles attachments, Quick Look previews, and structured health reports.
