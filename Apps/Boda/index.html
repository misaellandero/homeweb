Dress code

Etiqueta rigurosa (black tie) / Charro Gran Gala (etiqueta)

Así recordamos la inspiración visual de nuestra celebración.

Para invitadas

Vestidos largos de gala en tonos neutros u oscuros que armonicen con el verde olivo.

Para invitados

Preferentemente traje charro de gala o smoking con corbata o moño. Camisa blanca y zapato formal obligatorios.

Colores reservados

  • Hermanas de los novios
  • Damas
  • Novia

Prohibido

No se permiten atuendos casuales o informales, mezclilla, cortes o escotes muy pronunciados, tenis ni colores reservados para el cortejo.
