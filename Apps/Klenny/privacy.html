Klenny Privacy Notice

Last updated: November 20, 2026

Klenny is a macOS utility by Misael Landero. It is designed to lock keyboard and trackpad input while you clean your Mac.

Data Collection

Klenny does not collect, sell, rent, or share personal information. It does not include analytics, advertising SDKs, account creation, or a custom backend.

Version From This Website

The version downloaded from misaellandero.com connects to the internet only for two things:

  • License keys. When you activate, verify or deactivate a license key, Klenny sends the key, the app version and an activation identifier to Polar (polar.sh), the merchant of record that sells Klenny. It does not send your computer name or other personal data. Polar processes your purchase details (such as your email address and payment) under its own privacy policy.
  • Updates. Klenny checks misaellandero.com for new versions. Like any web request, this exposes your IP address and app version to the web host.

The Mac App Store version does not connect to the internet.

This Website

This website (not the app) uses GoatCounter to count visits. It uses no cookies, does not store IP addresses and collects no personal data. It only keeps aggregated counts: which pages are visited, the site or campaign link that referred the visit (for example utm_source), browser, operating system, country (derived from the IP address, which is not stored), language and screen size, plus clicks on the download and buy buttons. If your browser sends Do Not Track or Global Privacy Control, nothing is counted. When you open the Polar checkout from this website, the campaign parameters of the link you arrived with are passed to Polar with your order. See GoatCounter's privacy policy.

Keyboard Input

Klenny uses macOS input-blocking APIs only to suppress accidental input while cleaning. The app does not record, store, transmit, or inspect the contents of your keystrokes.

System Permissions

The version from this website requests Accessibility permission so it can block input system-wide during cleaning mode. These permissions are managed by macOS in System Settings.

Aviso de privacidad

Aviso de privacidad de Klenny

Última actualización: 20 de noviembre de 2026

Klenny es una utilidad para macOS de Misael Landero. Está diseñada para bloquear el teclado y el trackpad mientras limpias tu Mac.

Datos que recopila

Klenny no recopila, vende, renta ni comparte información personal. No incluye analítica, SDK de publicidad, creación de cuentas ni servidor propio.

Versión de este sitio web

La versión descargada de misaellandero.com solo se conecta a internet para dos cosas:

  • Llaves de licencia. Al activar, verificar o desactivar una llave, Klenny envía la llave, la versión de la app y un identificador de activación a Polar (polar.sh), el merchant of record que vende Klenny. No envía el nombre de tu equipo ni otros datos personales. Polar trata los datos de tu compra (como tu correo y el pago) según su propia política de privacidad.
  • Actualizaciones. Klenny consulta misaellandero.com para buscar versiones nuevas. Como cualquier solicitud web, esto expone tu dirección IP y la versión de la app al servidor del sitio.

La versión de la Mac App Store no se conecta a internet.

Este sitio web

Este sitio web (no la app) usa GoatCounter para contar visitas. No usa cookies, no guarda direcciones IP y no recopila datos personales. Solo conserva conteos agregados: qué páginas se visitan, el sitio o enlace de campaña desde el que llegaste (por ejemplo utm_source), navegador, sistema operativo, país (calculado a partir de la IP, que no se guarda), idioma y tamaño de pantalla, además de los clics en los botones de descarga y compra. Si tu navegador envía Do Not Track o Global Privacy Control, no se cuenta nada. Cuando abres el pago de Polar desde esta web, los parámetros de campaña del enlace con el que llegaste se envían a Polar junto con tu orden. Consulta la política de privacidad de GoatCounter (en inglés).

Lo que escribes

Klenny usa las API de bloqueo de entrada de macOS solo para suprimir pulsaciones accidentales mientras limpias. La app no registra, guarda, transmite ni inspecciona el contenido de tus pulsaciones.

Permisos del sistema

La versión de este sitio pide el permiso de Accesibilidad para poder bloquear la entrada a nivel sistema durante el modo de limpieza. macOS administra estos permisos en Ajustes del Sistema.
